
## OSS 6주차: 오픈소스 프로젝트 기본 구조 구축

### 1. 실습 개요

OSS 기반 SW 프로그래밍 6주차 과제로 공개 GitHub 저장소에 오픈소스 프로젝트 운영에 필요한 기본 문서와 라이선스를 구성하였습니다.

### 2. OSS 기본 구조

| 파일 | 주요 내용 |
|---|---|
| README.md | 프로젝트 소개, 기능 및 실습 내역 |
| LICENSE | MIT 라이선스 적용 |
| CONTRIBUTING.md | 프로젝트 기여 및 협업 규칙 |
| CODE_OF_CONDUCT.md | 참여자 행동 강령 |

### 3. OSS 라이선스 비교 분석 (선택 과제)

MIT, Apache License 2.0, GPL 3.0을 비교 분석하였습니다.

주요 비교 기준:
- 상업적 이용 및 재배포 조건
- 소스코드 공개 의무
- 저작권 및 특허 관련 조건
- 라이선스 호환성

프로젝트 규모와 재사용 편의성을 고려하여 MIT 라이선스를 선택하였습니다.

[라이선스 비교 분석 문서](docs/LICENSE_COMPARISON.md)

### 4. Inner Source 도입 로드맵 (선택 과제)

가상의 조직을 대상으로 오픈소스 협업 방식을 내부에 적용하기 위한 단계별 로드맵을 작성하였습니다.

도입 단계:
1. 준비 및 현황 분석 (1~2주)
2. 협업 환경 구축 (3~4주)
3. 시범 프로젝트 운영 (5~6주)
4. 평가 및 개선 (7~8주)
5. 조직 전체 확산 (9~12주)

GitHub 기반 Issue, PR, 코드 리뷰, Wiki, ADR 등을 활용하는 협업 체계와 성과 측정 지표를 정의하였습니다.

[Inner Source 도입 로드맵](docs/INNER_SOURCE_ROADMAP.md)

### 5. 실습 결과

- Public 저장소 및 OSS 기본 문서 구성
- MIT 라이선스 적용
- OSS 라이선스별 특징 및 선택 기준 비교
- Inner Source 단계별 도입 계획 수립

본 실습을 통해 오픈소스 프로젝트의 공개 및 운영에 필요한 기본 구조와 라이선스 관리 원칙을 학습하였습니다.
